# VetLoop Prototype

獸醫在環（human-in-the-loop）的照護 Prototype，參加 AIforPets 2027「獸醫照護」主題。
流程：AI 幫飼主整理問診 → 獸醫看摘要、開醫囑 → AI 把醫囑改寫成白話計畫 → **獸醫核可後**才送給飼主 → 照護期間定時提醒，飼主的回報再交給獸醫審。

## 模擬案例聲明

這個作品裡所有資料都是**模擬案例**：虛構的「示範動物醫院」「王醫師」、貓「麻糬」（飼主林小姐）、狗「豆豆」（飼主陳先生）。
沒有任何真實的診療資料，也不會連到真實的醫院。兩個畫面的右上角都常駐「模擬案例」標籤。

## 需求

- Python 3.12
- 已登入的 Claude CLI（`claude` 要在 `PATH` 裡；以 CLI 2.1.310 驗證過）。AI 呼叫都走 `claude --print`，每次約 5 到 12 秒；逾時 60 秒、失敗最多重試 1 次。
- 只用 Flask（`requirements.txt`），前端是原生 JS／CSS，不連任何 CDN。
- 環境變數 `VETLOOP_MODEL` 可換模型，預設 `claude-haiku-5-5`。

## 安裝與啟動

`.zshrc` 若有 export `PYTHONPATH`，先 `unset`，免得干擾虛擬環境。

```sh
unset PYTHONPATH
python3.12 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m vetloop.app
```

打開 <http://127.0.0.1:5050/>，首頁有三個入口：麻糬的手機（`/phone/1`）、豆豆的手機（`/phone/2`）、醫院後台（`/clinic`）。

- 資料庫在 `instance/vetloop.db`，上傳的照片在 `instance/uploads/`（兩者都不進版控）。第一次啟動會自動建立兩筆模擬案例。
- 後台的「重設示範資料」會清空所有對話、醫囑、提醒與上傳的照片，回到全新的兩筆案例。
- **只綁 127.0.0.1，沒有登入機制，僅供本機示範，請勿對外開放。**
- 背景有一條排程每 30 秒把到期的提醒送給飼主；Demo 時可用「快轉到下一個提醒」。

## Demo 腳本（建議錄影順序）

視窗並排：左邊 `/phone/1`（飼主；右側「系統紀錄」面板是示意用的，飼主在 LINE 上看不到，會逐格打勾），右邊 `/clinic`（醫院後台）。

1. **飼主問診**：在麻糬的手機傳「麻糬今天一直在吐」，系統用固定問句追問開始時間與次數（第一次回覆開頭固定是「收到，我幫您整理給醫院。想先確認：」）。
2. 回答「從昨天晚上開始，吐了三次」，並按「附上示範照片」：這會把 `vetloop/static/demo/vomit.png` 放進附件（輸入框上方出現縮圖），再按「送出」一起送出；也可用旁邊的圖示從檔案選。AI 只描述看得到的顏色與形狀，寫進「照片描述」；這段描述沒有經過獸醫核可，所以只出現在醫院端，飼主端（聊天室與系統紀錄面板）只看到「已收到照片」。
3. 回答食慾、精神、飲食變化：「不太想吃，精神還好，最近沒換飼料」。
4. 回答排泄與用藥：「排便正常，沒有吃藥」。欄位全部齊了，系統送出固定格式的整理（只列已記錄的項目與收到幾張照片，不回顯欄位值），按「正確，送出」。
5. **獸醫看摘要**：後台「案例列表」→「開啟案例」。摘要卡有時間軸、各欄位、飼主原話、照片加 AI 描述、待確認事項；沒有任何病名欄位。
6. **開醫囑**：例如藥名「示範藥A」、每日 2 次、飯後、5 天；飲食「當天少量多餐」2 天；回診 3 天；觀察重點「若持續嘔吐請來電」。補充欄位可按麥克風用國語口述（瀏覽器支援 Web Speech API 才會出現）。按「送出醫囑，產生照護計畫」，AI 產生約需數秒。
7. **核可照護計畫**：左邊是醫囑原文，右邊是計畫草稿：用藥行由系統照醫囑原文產生（和提醒用同一份資料），飲食、回診、觀察重點由 AI 改寫成白話；上方有護欄檢查結果（劑量必須出自醫囑、不得出現病名或診斷用語）。計畫文字不能直接改，要改就改左邊的醫囑重新產生；確認後按「核可並送出」。
8. 回到手機：飼主看到「這是王醫師的醫囑」加完整提示文字，並開始依醫囑收提醒。
9. **提醒與回報**：後台案例頁按「快轉到下一個提醒」，手機收到「該餵麻糬吃藥了」，按「已餵」（用過的按鈕會變灰）。
10. **獸醫審 AI 回覆**：飼主再傳「吃完藥又吐了一次」。系統只會回一句系統回條並建草稿，**AI 不會自己回答**。後台「待審佇列」出現變化摘要與回覆草稿，可編輯後核可送出；手機看到「（王醫師已確認）」。
11. **（選用）照護中修改醫囑**：獸醫看完回報，決定換藥或改次數時，不能在追蹤回覆裡寫「停藥」「改成每天一次」（核可時會被擋下，提示改用「修改醫囑」）。到後台案例頁，醫囑區塊下方展開「修改醫囑」，表單預填現行醫囑；例如藥名改「示範藥B」、每日 1 次、3 天，按「產生新的照護計畫」。案例列表與案例頁的標籤變成「照護中・新醫囑待核可」；核可之前飼主端沒有任何變化，提醒仍照舊醫囑送。在計畫區塊按「核可並送出」後，手機收到「這是王醫師更新後的醫囑」加完整提示文字；舊版還沒送出的提醒取消，改照新醫囑重新排程，已送出的提醒不受影響、按鈕照常能按。
12. **緊急情境**：在豆豆的手機傳「牠剛剛好像吞了一段繩子」。飼主立刻收到固定話術（請立即致電醫院），不經 AI；後台「緊急通知」整塊轉紅，按「知道了」標為已讀。
13. 錄完用「重設示範資料」回到起點。

## 提示文字（附在所有給飼主的健康相關內容）

照護計畫訊息附完整提示文字：

> 本作品提供之資訊僅供輔助參考，不能取代獸醫師之診斷、治療或專業建議。貓犬之健康與營養需求可能因個體狀況而異，如有健康疑慮或需要調整飲食與照護方式，請諮詢合格獸醫師。

提醒訊息與獸醫核可的回覆附短提示：

> 提醒內容來自獸醫師醫囑，僅供照護參考；有疑慮請洽獸醫師。

手機畫面上這兩段用小字顯示，但一個字都不省略。

## 護欄

**AI 不自動送出任何自由文字給飼主。** 自動送給飼主的訊息只有四種，全部是固定模板：

1. 追問：固定問句（開始時間、次數、食慾與精神、飲食變化、排泄、用藥），AI 只負責從飼主原話擷取欄位，不寫追問。
2. 確認訊息：「我整理如下，請確認：」加「已記錄：狀況、開始時間…」與「照片：已收到 N 張」。不回顯欄位值：AI 從飼主訊息挑出來的句子可能切掉「我沒有說」這類否定或引用語境，所以挑出來的值只給醫院看；飼主自己的原話本來就在聊天室裡。
3. 緊急固定話術：偵測到緊急字眼時不經 AI，直接請飼主致電醫院並通知櫃台。
4. 系統回條（「收到，已轉給醫院。」之類）。

其餘給飼主的健康內容（照護計畫、照護期間的追蹤回覆）一律獸醫核可才送出，核可後原樣轉達並標明「這是王醫師的醫囑」。

提醒是照醫囑排的，所以**追蹤回覆不能用來改藥**：核可時若文字含停藥、改次數、加減量、換藥這類字眼，系統會擋下並提示改用案例頁的「修改醫囑」，草稿維持待審、什麼都不送。照護中修改醫囑時，新版先存成待核可的版本，現行醫囑與提醒維持原樣；核可新計畫時才在同一個交易裡換上新版、取消舊版還沒送出的提醒並重新排程。改醫囑前寫好、還在待審的 AI 回覆草稿會作廢，換成請人員照現行醫囑重寫；回覆提到現行醫囑已經沒有的藥、或新版還沒核可的藥，核可時都會被擋下。

AI 產出的內容（欄位值、照片描述、摘要、計畫與回覆草稿）另外過護欄：不得出現病名、疑似／可能是、診斷、嚴重度或風險分級、用藥或劑量建議，也不得出現任何飼料、產品或品牌。飼主端（確認訊息與系統紀錄面板）不顯示任何欄位值與照片描述，只顯示「已記錄」；醫院端照原值顯示。草稿上的護欄標記只是提醒獸醫，不會替他擋下或改寫。

## 已知限制

- 護欄是關鍵字與規則比對，擋不完所有說法，所以才把會直接送給飼主的內容限制在固定模板，其餘交給獸醫審核。
- 緊急字眼寧可誤報也不漏報（例如「沒有誤食」也會觸發通知）。
- 追蹤回覆的改藥字眼檢查是 regex 經驗法則，不是語意判斷：擋不到沒出現這些字眼的說法（例如「晚上那一次不用吃」），也會誤擋少數正常句子（例如「劑量」「藥量」單獨出現就擋，請獸醫換個寫法）。
- 資料表結構有改過（訊息、草稿、提醒、通知的 id 不會重複使用；計畫草稿記錄醫囑版本；案例記錄重設世代與照護中待核可的新版醫囑 `revision_json`）；舊的 `instance/vetloop.db` 不會自動升級，請刪掉它再啟動，否則會出現 `no such column` 錯誤。

## 測試

測試全程使用假的 LLM，不會呼叫真的 Claude CLI：

```sh
unset PYTHONPATH
.venv/bin/python -m unittest -v
```

## 目錄

```
vetloop/
  app.py         Flask 路由、提醒排程 thread
  flows.py       問診、醫囑、計畫、提醒的流程
  guardrail.py   護欄（純函式）與提示文字
  llm.py         呼叫 Claude CLI（有逾時與重試上限）
  db.py          SQLite 資料表與示範資料
  templates/     Jinja 模板
  static/        原生 JS／CSS；demo/vomit.png 是示範照片
tests/           unittest
```
